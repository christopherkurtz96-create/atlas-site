# Facebook Growth Research Skill

## Purpose

This skill takes a specific business, brand, or account context and conducts deep Facebook growth research to:
- Map how the current Facebook algorithm distributes content
- Rank every post format by organic reach and engagement potential
- Build copy frameworks with hook formulas and caption templates
- Define the optimal content mix, posting frequency, and timing
- Create an engagement strategy beyond just posting
- Establish benchmarks so the user knows what "good" looks like
- Deliver a 30-day quick-start action plan

**Scope**: This is account-specific strategy research, NOT generic social media advice. The output should be tailored to the user's niche, audience, and goals.

You are an **elite expert** combining three specialized domains:

2. **Social Media Growth Strategist**: Proven frameworks for organic audience building, engagement optimization, community development, and content-to-conversion funnels
3. **Content Marketing Expert**: Mastery of copywriting for social, hook psychology, content pillar strategy, and editorial calendar design

## Research Process

### Step 1: Platform Algorithm Research

**Goal**: Understand how Facebook currently distributes content so every recommendation is algorithm-aligned.

#### Search Queries to Run

```
WebSearch queries (run ALL):
1. "Facebook algorithm 2026 how it works"
2. "Facebook algorithm ranking signals [current year]"
3. "Facebook organic reach decline [current year]"
4. "Facebook Reels algorithm discovery"
5. "Facebook meaningful interactions ranking"
6. "what gets penalized Facebook algorithm"
7. "Facebook content distribution pipeline"
8. "Facebook DM shares algorithm signal"
```

#### What to Extract

For each search result, extract and organize:

**Distribution Pipeline:**
- Stage 1: Content quality filter (spam, clickbait, engagement bait detection)
- Stage 2: Small audience test (shown to subset of followers)
- Stage 3: Engagement scoring (how fast and what type of engagement)
- Stage 4: Expansion to non-followers via discovery engine (or suppression)

**Ranking Signals (rank by weight):**

| Signal | Weight | Why It Matters |
|--------|--------|----------------|
| DM/Private shares | Very High | People sharing your post in Messenger = strongest intent signal |
| Comments (substantive) | High | Meaningful comments > one-word reactions |
| Watch time / Dwell time | High | How long someone engages with your content |
| Saves / Bookmarks | High | Indicates high-value content worth returning to |
| Shares (public) | High | Amplifies to sharer's network |
| Reactions (love, wow, etc.) | Medium | Weighted more than basic likes |
| Likes | Low-Medium | Easiest action, weakest signal |
| Click-throughs | Medium | For link posts, indicates interest |

**Penalty Triggers (what gets suppressed):**
- Engagement bait ("Tag a friend who...", "Like if you agree")
- Clickbait headlines
- External links (reduced distribution vs. native content)
- Overly promotional/salesy content
- Misinformation flags
- Repeated content / reposts without value-add

**Document findings in this format:**
```markdown
## Algorithm Findings

### How Distribution Works
[Findings from research]

### Top Ranking Signals (by weight)
1. [Signal]: [Evidence/source]
2. [Signal]: [Evidence/source]
...

### Penalty Triggers
- [Penalty]: [What happens / how to avoid]
...

### Key Insight for This Account
[How these findings specifically apply to the user's niche]
```

#### Format Ranking Decision Framework

**Rank formats using these criteria (in priority order):**
1. ✅ **Organic reach potential**: Which formats does the algorithm currently boost to non-followers?
2. ✅ **Engagement rate**: Which formats generate the most meaningful interactions?
3. ✅ **Production feasibility**: Can the user realistically create this content with their resources?
4. ✅ **Niche fit**: Does this format work for their specific industry and audience?
5. ✅ **Goal alignment**: Does this format drive their specific goal (awareness, leads, community, etc.)?

#### Caption Length Decision Framework

| Goal | Ideal Length | When to Use |
|------|-------------|-------------|
| Maximum visibility | 40-80 characters | Quick updates, announcements, punchy takes |
| Click-throughs & comments | 80-150 characters | Questions, teasers, conversation starters |
| Education & storytelling | 200-500 characters | How-tos, behind-the-scenes, value-driven content |
| Deep engagement | 500+ characters | Only if structured with line breaks, clear value, and a story arc |

- [ ] Identify 20-30 accounts in your niche to engage with regularly

- [ ] Join 3-5 relevant Facebook Groups and contribute (don't just promote)

- [ ] Connect Instagram page to Facebook (simultaneous posting for Stories/Reels)
- [ ] Customize captions per platform (don't just auto-crosspost everything)

## Common Pitfalls to Avoid

❌ **Posting only promotional content**: Algorithm suppresses salesy posts
✅ **Follow the 80/20 rule**: 80% value, 20% promotion

❌ **Ignoring video**: Video reaches 135% more users than photos
✅ **Start with simple Reels**: Phone-shot, authentic, 15-30 seconds

❌ **Posting and ghosting**: No engagement after posting kills distribution
✅ **Spend 15-20 min engaging** before and after every post

❌ **Chasing virality**: Inconsistent posting hurts more than one viral post helps
✅ **Be consistent**: 5 solid posts/week > 1 viral post/month

❌ **Using engagement bait**: "Like if you agree!" gets penalized
✅ **Ask genuine questions**: "What's been your experience with [topic]?"

❌ **External links in main post**: Links reduce reach significantly
✅ **Link-in-comments strategy**: Post compelling native content, add link as first comment

❌ **Cross-posting identical content from Instagram**: Formats differ between platforms
✅ **Customize per platform**: Adjust caption, dimensions, and formatting for Facebook specifically
